### User Guide: How to Upload and Manage Assets in Recorded Web Application

#### 1. Purpose
This guide provides detailed instructions for users on how to upload and manage assets within the Recorded Web Application. It covers the process from logging in to uploading files and editing their details.

#### 2. Scope
This guide is intended for users of the Recorded Web Application who need to upload and manage digital assets such as images or documents. It is especially useful for content managers, digital asset managers, and users with administrative permissions to upload and modify content within the platform.

#### 3. Prerequisites
- Active account with login credentials
- Access to a supported web browser (e.g., Chrome, Firefox, Safari)
- Necessary permissions to upload and manage assets in the application
- Files prepared for upload

________________________________________

#### 4. Steps

**Step 1: Logging into the Recorded Web Application**
1. Open your preferred web browser.
2. Navigate to the login page of the Recorded Web Application at `https://dev.mirrix.app/login`.
3. Enter your username and password in the respective fields.
4. Click the `Login` button.
   - ![Login Page](placeholder_image.jpg)
   - Expect to be redirected to the main dashboard upon successful login.

**Step 2: Navigating to the Upload Page**
1. From the main dashboard, click on the `Assets` tab or navigate directly to `https://dev.mirrix.app/assets`.
2. Click the `Upload` button located on the assets page.
   - ![Upload Button](placeholder_image.jpg)
   - You should now be on the `https://dev.mirrix.app/assets/upload` page.

**Step 3: Uploading Files**
1. Click the `Select files` button to open the file chooser dialog.
2. Navigate to and select the files you wish to upload.
3. After selecting the files, choose the `Upload` type by clicking the `Default` or `Images` button, depending on your file type.
   - ![Select Files](placeholder_image.jpg)
4. Optionally, enter a description for the batch of files in the `Description field`. Start with "Test_batch_" followed by the specific batch identifier (e.g., "Test_batch_1501").
5. Click the `Upload` button to start the upload process.
   - Expect to see a progress indicator, such as `Waiting...`, that updates to `100%` and finally to `Completed` as the file uploads successfully.
   - ![Upload Progress](placeholder_image.jpg)

**Step 4: Managing Uploaded Files**
1. After uploading, navigate to your uploaded files by clicking on the file's name, e.g., `IMG_142781`.
2. Edit file details such as `Image Description:`, `Object Type:`, and `File details` by clicking on the respective buttons and entering the required information.
3. For extended file attributes like `Alt Text`, `Background Color`, `Brand`, etc., click the corresponding button to enter or edit this information.
   - ![File Details](placeholder_image.jpg)
4. Once all desired changes are made, navigate through the file's additional options using the `Preview`, `Edit in Adobe`, `Create variation`, and `Edit in Canva` buttons as needed.
5. To finalize your session, click the `Logout` button to securely exit the application.

________________________________________

#### 5. Troubleshooting

| Issue | Solution |
|-------|----------|
| Unable to log in | Ensure you are using the correct login credentials. If you have forgotten your password, use the "Forgot Password" link. |
| File upload fails | Check the file size and format. Ensure it meets the application's requirements. If the issue persists, try refreshing the page and uploading again. |
| Changes to file details not saving | Make sure to click any `Save` or `Done` buttons after making changes. If there's no such option, ensure you've clicked outside the editable field to trigger auto-save. |
| Cannot find the `Upload` button | Verify you are on the correct page (`https://dev.mirrix.app/assets/upload`). If you are, refresh the page or clear your browser cache. |
| Uploaded file does not appear | Refresh the assets page. If the file still doesn’t appear, check if the upload was successful, and retry if necessary. |

________________________________________

#### 6. Tips
- Always verify the file type and size before uploading to ensure compatibility with the platform.
- Use descriptive batch names for easier identification and management of uploaded files.
- Regularly update your browser to the latest version for optimal performance and security.
- Log out from the application after finishing your session to maintain account security.
