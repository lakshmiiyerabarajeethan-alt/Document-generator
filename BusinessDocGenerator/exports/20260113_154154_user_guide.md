# User Guide: How to Upload and Manage Assets on Sample Application

## 1. Purpose
This guide provides detailed instructions on how to upload and manage digital assets on the Sample application. It covers the process from logging in to uploading files and logging out safely.

## 2. Scope
This guide is intended for users of the Sample application who need to upload, label, and manage digital assets. It is particularly useful for content managers and digital librarians with the necessary permissions to access and upload content.

## 3. Prerequisites
Before starting, ensure you have:
- Access credentials (username and password) for the Sample application.
- A stable internet connection and a modern browser (e.g., Chrome, Firefox, Safari).
- Necessary permissions to upload and manage digital assets within the application.

________________________________________

## 4. Steps

### Step 1: Navigate to the Login Page
1. Open your web browser.
2. Enter the URL `https://dev.mirrix.app/login` in the address bar.
3. Press Enter.  
   **Expected Outcome**: The login page of the Sample application loads.

### Step 2: Log In
1. Click on the Password field.
2. Enter your password. Remember to keep your password secure and not share it with others.  
   **Expected Outcome**: The password is entered but displayed as masked characters for security.

3. Click the "Login" button.  
   **Expected Outcome**: You are redirected to the main assets page at `https://dev.mirrix.app/assets`.

### Step 3: Upload Files
1. Click the "Upload" button.  
   **Expected Outcome**: The file selection dialog opens.

2. Click the "Select files" button.  
   **Expected Outcome**: A file explorer window opens.

3. Navigate to and select the file(s) you wish to upload. Click "Open" in the file explorer window.  
   **Expected Outcome**: The selected file's path appears in the input field.

4. Click the "Default" button if required, then click the "Images" button to specify the type of asset you are uploading.  
   **Expected Outcome**: The asset type is set to images.

5. Enter a description for the batch in the "Description field". Start with "Test_funny_image_" followed by any specific identifiers (e.g., "Test_funny_image_1301").  
   **Expected Outcome**: The description for the batch is set.

6. Tag the images by entering keywords like "toy", "blocks", "girls" in the input fields and clicking the button after each entry.  
   **Expected Outcome**: The tags are added to the upload.

7. Click the "Upload" button to start the upload process.  
   **Expected Outcome**: The upload process begins, indicated by the "Waiting...", then "Uploading... 100%" status updates.

### Step 4: Finalize Upload
1. Once the upload status shows "Uploading... 100%", click the "Completed" button.  
   **Expected Outcome**: The upload is confirmed as completed.

2. Optionally, review the uploaded assets by clicking on their identifiers (e.g., "IMG_142731").  
   **Expected Outcome**: The details or preview of the uploaded asset is displayed.

### Step 5: Logout
1. Click the "Logout" button.  
   **Expected Outcome**: You are logged out and redirected to the login page `https://dev.mirrix.app/login`.

## 5. Troubleshooting

| Issue | Solution |
|-------|----------|
| Cannot log in | Ensure you are using the correct password. If forgotten, use the password reset feature. |
| File not uploading | Check the file type and size limits. Ensure you have the necessary permissions to upload assets. |
| Upload seems stuck | Refresh the page and try uploading again. If the issue persists, check your internet connection. |
| Cannot logout | Clear your browser's cookies and cache, then attempt to logout again. |
| Tags not saving | Ensure you click the button after entering each tag. If the issue persists, try refreshing the page. |

________________________________________

## 6. Tips (Optional)

- Always verify the file path and name before uploading to avoid mistakes.
- Use descriptive tags for easier searching and organizing of assets.
- Regularly update your password and keep it secure to prevent unauthorized access.
