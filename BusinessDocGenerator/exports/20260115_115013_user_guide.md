### How to Upload and Manage Assets in the Mirrix Web Application

#### 1. Purpose
This guide provides detailed instructions on how to upload and manage digital assets using the Mirrix Web Application. It helps users efficiently navigate the platform, upload files, and manage asset information.

#### 2. Scope
This guide is intended for users of the Mirrix Web Application who need to upload and categorize digital assets. It is suitable for users with permissions to access the asset management and upload features of the platform.

________________________________________

#### 3. Prerequisites
- Active account with login credentials for the Mirrix Web Application.
- Access to a device with an internet connection and a web browser (recommended: latest versions of Chrome, Firefox, or Safari).
- Necessary permissions to upload and manage digital assets within the application.

________________________________________

#### 4. Steps

**Step 1: Log in to the Mirrix Web Application**
1. Open your web browser and navigate to `https://dev.mirrix.app/login`.
2. Enter your username and password in the designated fields.
3. Click the "Login" button.
   - Expect to be redirected to the main dashboard of the Mirrix Web Application.

**Step 2: Navigate to the Asset Upload Page**
1. Once logged in, navigate to `https://dev.mirrix.app/assets` by clicking the "Assets" section on the dashboard or main menu.
2. Click the "Upload" button to proceed to the asset upload interface.

**Step 3: Upload Digital Assets**
1. Click the "Select files" button.
2. A file dialog box will appear. Select the file(s) you wish to upload from your device.
3. After selecting the file(s), click the "Open" button in the dialog box to confirm your selection.
4. Click the "Upload" button to start uploading the selected file(s) to the platform.
   - Wait for the upload process to complete. You may see a "Waiting..." button that will change to "Completed" once the upload is successful.

**Step 4: Manage Asset Information**
1. After successful upload, click on the asset you wish to manage (e.g., "IMG_142775").
2. To add or edit asset metadata, click on the "Extended Info" button and fill in the fields such as Alt Text, Background Color, etc.
3. For setting user-maintained attributes, click on the "User-Maintained Attributes" button and provide necessary details like Usage Rights Expiry and Region.
4. Confirm the changes by clicking the corresponding confirmation button at the bottom of the section.

**Step 5: Log Out**
1. Once you have completed managing your assets, click the "Logout" button to securely exit the Mirrix Web Application.
   - Expect to be redirected to the login page, confirming that you have been successfully logged out.

________________________________________

#### 5. Troubleshooting

| Issue | Solution |
|-------|----------|
| Cannot log in | Ensure you are using correct login credentials. If forgotten, use the "Forgot Password" link to reset. |
| Upload fails | Check the file size and format. Ensure they meet the platform's requirements. Try uploading again. |
| Cannot find the upload button | Ensure you have the necessary permissions. If the issue persists, refresh the page or try a different browser. |
| Metadata changes not saving | Make sure all required fields are filled. If the problem continues, try logging out and back in, then retry. |
| Logout issues | Clear your browser's cache and cookies, then attempt to log out again. |

________________________________________

#### 6. Tips
- Double-check file types and sizes before uploading to ensure compatibility and to avoid errors.
- Regularly update your password and keep your login credentials confidential for security.
- Use descriptive names and comprehensive metadata for assets to make searching and categorization easier.
