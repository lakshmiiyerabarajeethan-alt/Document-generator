# User Guide: Managing Assets in the Web Application

## 1. Purpose
This guide provides detailed instructions on how to navigate the Web Application to upload and manage digital assets effectively. It helps users through the process of logging in, uploading files, and updating asset information.

## 2. Scope
This guide is intended for users who need to manage digital assets within the Web Application. It is particularly useful for content managers, digital asset managers, and administrative staff who have been granted the necessary permissions to upload and edit asset information.

________________________________________

## 3. Prerequisites
To complete the steps in this guide, you will need:

- An active account with login credentials.
- A compatible web browser (Mozilla/5.0 or later recommended).
- Necessary permissions to upload and manage assets in the application.

________________________________________

## 4. Steps

### Step 1: Navigate to the Login Page
1. Open your web browser.
2. Enter the URL for the Web Application login page: `https://dev.mirrix.app/login`.
3. Press `Enter` to proceed.  
   _Expect to see the login page._

### Step 2: Log In
1. Locate the "Password field" and enter your password. Remember to keep your password secure.  
   ![Enter Password](placeholder_image.jpg)
2. Click the `Login` button.  
   _After successfully logging in, you will be redirected to the assets management page._

### Step 3: Navigate to the Assets Page
1. If not automatically redirected, navigate to `https://dev.mirrix.app/assets`.  
   _This page displays all available digital assets._

### Step 4: Upload New Asset
1. Click the `Upload` button.
2. In the dialog that appears, click the `Select files` button.  
   ![Select Files](placeholder_image.jpg)
3. Choose the file you wish to upload from your computer.
4. After selecting the file, click the `Default` button to proceed with the default upload settings.
5. Confirm the file selection by clicking the `Images` button, indicating the type of asset you are uploading.
6. Start the upload by clicking the `Upload` button again.  
   _Wait for the "Waiting..." button to change to "Completed" indicating that your upload is finished._

### Step 5: Edit Asset Information
1. Find and click on the asset you uploaded, identified by its name (e.g., `IMG_142775`).
2. To add or edit additional information, click on the `Extended Info` button and fill in the necessary fields such as Alt Text, Background Color, etc.
3. Click the `User-Maintained Attributes` button to specify usage rights and confidentiality levels.
4. Click the `Asset class` button to define technical attributes of the asset.
5. Once all necessary information is entered, click the `Uploaded: 2026-01-15` button (or the relevant button indicating the current date) to save changes.

### Step 6: Log Out
1. Ensure all changes are saved.
2. Click the `Logout` button to securely exit the application.  
   _You will be redirected to the login page, confirming that you have been logged out._

## 5. Troubleshooting

| Issue | Solution |
|-------|----------|
| Unable to log in | Verify that you are using the correct password and have an active account. If issues persist, reset your password or contact support. |
| Upload fails | Check the file size and format. Ensure you have a stable internet connection. Try uploading the file again. |
| Cannot edit asset information | Ensure you have the necessary permissions to edit assets. If the problem persists, refresh the page or clear your browser's cache and try again. |

________________________________________

## 6. Tips
- Always log out after your session to maintain security.
- Use descriptive names for your assets to make them easier to find and manage.
- Regularly update your password to enhance account security.
