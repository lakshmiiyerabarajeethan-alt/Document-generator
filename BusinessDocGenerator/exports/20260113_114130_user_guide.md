### Guide to Uploading and Managing Assets on Mirrix

#### 1. Purpose
This guide provides detailed instructions on how to log in to the Mirrix platform, upload assets, and manage them. It is designed to help users efficiently navigate the site, upload images or files, and handle uploaded assets.

#### 2. Scope
This guide is intended for registered users of the Mirrix platform who need to upload and manage digital assets. It is suitable for users with basic computer skills and those authorized to add or modify assets within the platform.

#### 3. Prerequisites
- A valid Mirrix account with login credentials.
- Access to a device with internet connectivity and a modern web browser (e.g., Chrome, Firefox, Safari).
- Necessary permissions to upload and manage assets on the platform.

________________________________________

#### 4. Steps

**Step 1: Log in to Mirrix**
1. Navigate to [Mirrix Login Page](https://dev.mirrix.app/login).
2. In the "Password field," enter your password. Remember, for security reasons, ensure that your password is kept confidential. 
3. Click the "Login" button. Upon successful login, you will be redirected to the assets overview page.

**Step 2: Navigate to the Upload Page**
1. From the assets overview page, click on the "Upload" button or navigate directly to [Upload Page](https://dev.mirrix.app/assets/upload).

**Step 3: Upload an Asset**
1. On the Upload Page, click the "Upload" button.
2. Select the file you wish to upload from your computer. You can type the path directly into the "Input field" or use the file dialog that opens.
3. After selecting the file, click the next "Upload" button to start the upload process.
4. Monitor the upload progress. You will see a "Waiting...", followed by "Uploading... 100%", and finally, a "Completed" status indicating that the upload has finished successfully.

**Step 4: Add Description to the Uploaded Asset**
1. In the "Description field," gradually type the description for your asset (e.g., "Test_1301"). This description should provide context or information related to the asset you've uploaded.
2. After entering the description, proceed by clicking the next button to finalize the description entry.

**Step 5: Manage Uploaded Assets**
1. To view or manage your uploaded asset, navigate to its specific page by clicking on the asset's name or identifier (e.g., "IMG_142706").
2. After reviewing or making changes to your asset, you can return to the assets overview page by navigating back or clicking on a designated button.

**Step 6: Logout**
1. Once your tasks are completed, ensure to securely log out by navigating to the [Logout Page](https://dev.mirrix.app/login) and clicking the "Logout" button.

#### 5. Troubleshooting

| Issue | Solution |
|-------|----------|
| Unable to log in | Ensure you are using the correct password and have an active internet connection. If problems persist, reset your password or contact support. |
| Upload fails | Check the file size and format are supported by Mirrix. If the issue continues, try uploading at a different time or contact support for assistance. |
| Description not saving | Ensure that you click the button to finalize the description after typing. If it still doesn't save, refresh the page and try again. |
| Cannot find the uploaded asset | Verify if the upload was successful and check the 'Completed' status. If missing, re-upload the asset or contact support. |
| Logout issues | If unable to logout, clear your browser cookies and cache, then try again. For persistent issues, use another device or contact support. |

________________________________________

#### 6. Tips
- Always double-check the asset and description before finalizing the upload.
- Use descriptive names and detailed descriptions for easier asset management.
- Regularly update your password and ensure it remains confidential for security.
- For large files, ensure a stable internet connection to avoid upload interruptions.
